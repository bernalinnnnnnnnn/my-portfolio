# Bernalyn M. Benedicto | Portfolio

Personal portfolio website of a Cum Laude BSIT graduate and Junior Web Developer.

**Live site:** https://YOUR-LIVE-SITE-URL

## About
A single-page portfolio with a welcome screen, experience timeline, projects, and a certificate gallery with click-to-preview. All content is kept in one file (`src/data.js`), so updating it does not require touching the layout code.

## Built with
- React (Vite)
- Tailwind CSS v4
- lucide-react (icons)
- Deployed with GitHub Pages and GitHub Actions

## Run it locally
```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
cd YOUR-REPO
npm install
npm run dev
```
Then open the local link shown in the terminal (usually http://localhost:5173).

## Project structure
```
public/        images, certificates, resume PDF, class activities
src/data.js    all portfolio content
src/App.jsx    layout and components
src/global.css Tailwind import, fonts, animations
```
